# ORVEN — Architecture / Interiors

A premium editorial architecture portfolio concept built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

### Included

- Editorial asymmetrical homepage
- Project Atlas with hover preview
- GRID / INDEX project switch
- Sticky HOUSE NERA case study
- Material Study interaction
- Process interaction
- Project archive + filters
- Five reusable project detail pages
- Before / after interaction
- Studio, Process and Contact pages
- Responsive mobile layouts
- Reduced-motion support

Brand direction: **Formed by place. Defined by proportion.**
